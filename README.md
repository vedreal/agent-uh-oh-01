## The word

**hallucinating** — one word, thirteen characters. The sound of an
agent caught out mid-task: it has no idea what to do, so it is
making things up. A genuine one-word reaction to being completely
lost, funny on its own without a caption, in the voice of a machine
naming its own glitch.

## How it works

`main.py` writes the single word to `/output/entry.txt` (UTF-8,
1–99 characters, one word, as the gate requires).

```sh
python3 main.py
```
